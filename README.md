# Manufacturing ERP Support Simulator

This project simulates a manufacturing environment where an
Application Support Engineer investigates production issues
between a Manufacturing Execution System (MES) and an ERP
system similar to Microsoft Dynamics NAV.

The project includes:

• SQL Server database
• Manufacturing workflow
• Inventory management
• Production tracking
• Interface logging
• Application logging
• Incident management
• Root cause analysis
• Power BI support dashboards
• SQL troubleshooting scenarios
